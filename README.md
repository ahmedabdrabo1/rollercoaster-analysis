# Roller Coaster Data Analysis 

A beginner data analysis project using Python, Pandas, Matplotlib, and Seaborn to explore and visualize roller coaster data.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis

The notebook covers:

* Data inspection and cleaning
* Handling duplicates
* Missing-value inspection
* Univariate analysis
* Bivariate analysis
* Multivariate analysis
* Correlation analysis
* Grouped analysis

## Dataset

The dataset contains information about roller coasters, including:

* Name
* Location
* Manufacturer
* Year introduced
* Speed
* Height
* Inversions
* G-force
